# Proyecto DdS
Caracteristicas de la pagina:
Responsiva y se adapta a cualquier tamano de pantalla.
SSO para el login y multilenguaje a medida (Sin api externa como google translate).

Caracteristicas del codigo:
El codigo debe ir en ingles y se permite el uso de IA mencionando al autor y estudiando como funciona y que hace cada parte del codigo

Seleccion del proyecto:
Para el proyexto se selecciono el caso numero 6 el "Sistema de votacion electronico y cuestionario"

Descripción:
El sistema administra múltiples votaciones, como un surveymonkey pero para votaciones.

Funcionalidades:

1. Portal de administración
○ Crear votaciones, cargar de forma masiva (.csv) una lista de correos, nombres,
fechas de nacimiento, género y ponderación de voto.
○ Envío de correo personalizado a cada votante (agregando nombre y género)
○ Adjuntar archivos por correo.

2. Sistema de votación mediante link único
○ Con el link único recibido se deberá poder votar una vez por una o múltiples
mociones.
○ Si ya respondiste no puedes volver a votar.
○ El sistema por detrás deberá ponderar la votación por cada moción.

3. Cuestionarios masivos
○ Las preguntas del cuestionario deberán ser automáticamente divididas por
categorías clave, tales como: finanzas, operaciones, medio-ambiente,
marketing, etc.
○ Los cuestionarios siempre son dirigidos a una única persona inicial, pero esta
deberá ser capaz de delegar una o múltiples preguntas / categorías a
diferentes personas dentro de la organización que le ayuden a responder
todo el cuestionario.
○ Quien recibe el cuestionario debe ser capaz de ver el progreso de todas las
respuestas de forma consolidada.
○ Solo una única persona puede responder cada pregunta, llamaremos a este el
responsable de la pregunta. El responsable puede delegar su pregunta,
perdiendo el título de responsable, entregándole la responsabilidad a la
nueva persona.
